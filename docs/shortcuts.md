# Openhead Keyboard Shortcuts Reference

## Universal Shortcuts
| Shortcut | Action |
|---|---|
| `Cmd + K` / `Ctrl + K` | Open Command Palette |
| `Cmd + S` / `Ctrl + S` | Save Current Document / Sheet / Deck |
| `Cmd + Z` / `Ctrl + Z` | Undo last action |
| `Cmd + Shift + Z` / `Ctrl + Y` | Redo last action |
| `Cmd + F` / `Ctrl + F` | Search & Replace |
| `Cmd + P` / `Ctrl + P` | Print / Export to PDF |

## Pen (Document Editor)
| Shortcut | Action |
|---|---|
| `Cmd + B` / `Ctrl + B` | Toggle Bold |
| `Cmd + I` / `Ctrl + I` | Toggle Italic |
| `Cmd + U` / `Ctrl + U` | Toggle Underline |
| `Cmd + Shift + X` | Toggle Strikethrough |
| `Cmd + Alt + 1` | Heading 1 |
| `Cmd + Alt + 2` | Heading 2 |
| `Cmd + Alt + 3` | Heading 3 |
| `Cmd + Shift + 7` | Numbered List |
| `Cmd + Shift + 8` | Bullet List |

## Sum (Spreadsheet)
| Shortcut | Action |
|---|---|
| `F2` | Edit active cell |
| `Enter` | Commit edit and move down |
| `Tab` | Commit edit and move right |
| `Shift + Enter` | Move up |
| `Shift + Tab` | Move left |
| `Arrow Keys` | Navigate grid |
| `Alt + =` | AutoSum current column |
| `Ctrl + Space` | Select entire column |
| `Shift + Space` | Select entire row |

## Glimpse (Presentations)
| Shortcut | Action |
|---|---|
| `Cmd + Shift + Enter` / `F5` | Start Presenter Mode |
| `Right Arrow` / `Space` | Next slide |
| `Left Arrow` | Previous slide |
| `Escape` | Exit Presenter Mode |
| `Cmd + D` / `Ctrl + D` | Duplicate selected slide/shape |
