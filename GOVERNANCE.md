# Openhead Project Governance

Openhead is an independent, community-driven open-source project.

## Roles

- **Maintainers**: Responsible for overall architecture, release management, security reviews, and merging pull requests.
- **Module Leads**: Domain owners for Pen (Documents), Sum (Spreadsheets), Glimpse (Presentations), Formula Engine, and UI Design System.
- **Contributors**: Anyone who submits issues, pull requests, tests, or documentation.

## Decision Making Process

Major architectural changes must be proposed via an Architectural Decision Record (ADR) in `docs/adr/` and discussed publicly before implementation.
